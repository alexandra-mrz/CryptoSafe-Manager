# CryptoSafe Manager — руководство пользователя

Sprint 8 / DOC-2. Краткое руководство по основным сценариям работы с приложением.

---

## 1. Установка и запуск

### Из исходников

1. Установите Python 3.10+.
2. Клонируйте репозиторий и перейдите в каталог проекта.
3. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate          # Windows
   # source .venv/bin/activate     # macOS / Linux
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python run.py
   ```

   Альтернативы: `python -m src`, `python main.py`.

### Из собранного executable (Windows)

1. Соберите или распакуйте папку `dist/CryptoSafeManager/`.
2. Запустите `CryptoSafeManager.exe` **из этой папки** (все DLL должны лежать рядом).
3. При первом запуске откроется мастер настройки.

Подробнее о сборке: раздел «Упаковка» в [README.md](../README.md).

## 2. Мастер-пароль и vault

### Первый запуск

1. Запустите приложение — откроется **мастер первого запуска** (Setup Wizard).
2. Задайте **мастер-пароль** (дважды для подтверждения). Требования: достаточная длина и сложность (цифры, регистр, спецсимволы).
3. Укажите путь к файлу базы данных (по умолчанию `data/cryptosafe.db`).
4. После завершения мастера vault создан и зашифрован.

> **Важно:** мастер-пароль не восстанавливается. Без него доступ к записям невозможен.

### Разблокировка

При каждом запуске (или после блокировки) введите мастер-пароль в диалоге **Unlock vault**.

![Диалог разблокировки](screenshots/login_dialog.png)

### Смена мастер-пароля

Меню **Файл → Сменить мастер-пароль**. Потребуется текущий пароль; все записи перешифровываются новым ключом.

### Блокировка

- **Вид → Заблокировать** или горячая клавиша **Ctrl+L**.
- Автоблокировка по неактивности — настраивается в **Настройки → Безопасность**.
- **Режим паники** — **Ctrl+Shift+P** (очистка буфера, блокировка, скрытие окна).

## 3. Записи vault: добавление, изменение, удаление

### Главное окно

Список записей с колонками Title, Username, URL, Tags. Строка поиска фильтрует записи в реальном времени.

![Главное окно](screenshots/main_window.png)

### Добавить запись

1. **Правка → Добавить** или **Ctrl+N**.
2. Заполните поля: название, логин, пароль, URL, заметки, теги.
3. Кнопка генератора пароля создаёт случайный надёжный пароль.
4. **Сохранить**.

### Изменить запись

1. Выберите строку в таблице.
2. **Правка → Изменить** или двойной щелчок.
3. Отредактируйте поля и сохраните.

### Удалить запись

1. Выберите запись.
2. **Правка → Удалить** или **Delete**.
3. Подтвердите удаление (мягкое удаление с возможностью восстановления из корзины в настройках, если включено).

### Копирование полей

Контекстное меню или кнопки в таблице: копировать логин / пароль / заметку в защищённый буфер (см. раздел 4).

## 4. Защищённый буфер обмена

CryptoSafe Manager копирует секреты с **автоочисткой** и **маскированием** в системном буфере.

### Как пользоваться

1. Разблокируйте vault.
2. Скопируйте пароль или логин из записи (кнопка или контекстное меню).
3. Вставьте в нужное приложение в течение таймаута (по умолчанию 30 с).
4. Буфер очищается автоматически; в строке состояния отображается обратный отсчёт.

### Настройки

**Настройки → Безопасность → Таймаут буфера обмена** (5–300 с, 0 = без автоочистки).

### Ручная очистка

**Правка → Очистить буфер**.

### Подозрительная активность

Если содержимое буфера изменено извне, приложение может ускоренно очистить секрет и (опционально) заблокировать дальнейшее копирование до разблокировки.

## 5. Импорт и экспорт данных

### Экспорт vault

1. **Данные → Экспорт...**
2. Выберите формат: зашифрованный JSON, CSV, Bitwarden JSON, LastPass CSV и др.
3. Задайте **пароль файла экспорта** (отдельный от мастер-пароля).
4. Укажите путь сохранения.

![Диалог экспорта](screenshots/export_dialog.png)

### Импорт

1. **Данные → Импорт...**
2. Выберите файл (JSON, CSV, Bitwarden, LastPass, share-пакет).
3. Введите пароль файла, если он зашифрован.
4. Выберите режим: **объединить**, **заменить** или **пробный прогон** (dry run).

### Обмен одной записью (Share)

1. **Данные → Обмен записью...**
2. Выберите запись, способ (пароль / публичный ключ / ссылка), срок действия.
3. Сохраните `share.json`, QR-код или ссылку `cryptosafe://share/...`.

### QR-код

- **Данные → Сканировать QR (камера)...** — импорт ключа контакта или share-пакета (нужны `pyzbar`, камера).

### Резервная копия

**Файл → Резервная копия** — копия файла БД (рекомендуется хранить отдельно от мастер-пароля).
