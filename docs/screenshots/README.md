# Скриншоты для документации (DOC-1)

Файлы в этой папке используются в [README.md](../../README.md) и [user_guide.md](../user_guide.md).

| Файл | Экран / функция |
|------|-----------------|
| `main_window.png` | Главное окно, список записей, поиск |
| `login_dialog.png` | Разблокировка vault (мастер-пароль) |
| `export_dialog.png` | Экспорт данных (форматы, пароль файла) |
| `settings_dialog.png` | Настройки безопасности (буфер, auto-lock) |

При обновлении UI переснимите те же сцены в том же разрешении (~1280×720), чтобы документация оставалась актуальной.
